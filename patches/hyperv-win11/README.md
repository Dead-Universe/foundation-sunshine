# Sunshine 维护补丁

上游基线：`d549e16a3fa0887d26beb98eaa40785c1814b353`。维护源码：`e230b3d041f675e8bf5d053a3061974a8c19a3b2`，结果树 `90d64bc996ed9207e6c2599f7abcdcd46321f1c3`。顺序及 SHA256 见 [series.json](series.json)。宿主机上游快照保持干净，源码修改和构建仅在 Win11 虚拟机进行。

| 顺序 | 补丁 | 保留功能 |
| --- | --- | --- |
| 1 | `0001-hyperv-vdd-capture-recovery.patch` | VDD 采集选择、失败诊断、显示恢复、启动唤醒与 Auto 输出恢复 |
| 2 | `0002-nvenc-delayed-completion.patch` | 编码完成事件迟到时有界等待，避免提前销毁未完成帧 |
| 3 | `0003-hyperv-console-continuity.patch` | 服务会话 0 Core、控制台输入与显示助手、会话迁移后采集重建、串流期间显示请求及旧驱动光标生产者权限兼容 |
| 4 | `0004-offline-vbcable-installer.patch` | 捆绑标准 VB-CABLE 原包，保留已有和共享声卡 |

2026-10-30 的第二轮修正仍只更新第 3 份补丁，其余三份补丁字节保持不变。增强会话登录后再从 Moonlight 解锁控制台，会替换 VDD swap chain。官方 ZakoVDD 0.18.2 由 LocalService 创建光标共享内存和事件，却只在 DACL 中授权 SYSTEM、管理员及只读交互用户。消费者持有旧对象时，生产者重新创建同名对象会收到错误 5，随后停止光标导出。现场 ETW 捕获了这条错误路径；独立进程使用实际 WUDFHost 身份，对共享内存和事件均复现了相同失败。

Sunshine 在附着光标通道时，只对 LocalService 所有、权限精确匹配旧驱动格式的两个光标对象补入 OWNER RIGHTS 完全访问项。该项保留对象所有者重新打开自己对象的能力，不给交互用户增加写权限；遇到不同所有者或其他权限结构则不修改。重复执行无额外修改。客户端、显卡选择、配对和用户电源策略不变，无需替换或重签驱动。

专项回归源码见 [tests/cursor_acl_probe.cpp](tests/cursor_acl_probe.cpp)。使用已应用补丁的源码根目录作为 include 路径，并定义 `TEST_CURSOR_PRODUCER_REPAIR`，在虚拟机的临时 SYSTEM 诊断任务中执行：两个实际生产者身份下，原权限的共享内存/事件重开均报错 5，生产修正函数处理后均成功；重复调用不再改动，错误所有者和额外 ACE 场景不修改对象。所有测试对象使用独立临时名称，退出后关闭。

原生构建和 39 项 CTest 零失败。运行版 `2026.1030.234151.e230b3d0` 已可回滚替换并重启，仅替换主程序；配置、配对、官方驱动及服务配置保留。受控 RDP 到控制台迁移时，同一个服务 Core 保持运行；ETW 记录光标生产者正常重建，没有光标创建错误 5。鼠标移动后，Windows 及共享元数据均显示光标可见，位置同步，远端开始菜单响应正常，两次停止应用后从正常图形入口重新连接均显示实际桌面。自动化鼠标位置验证临时使用绝对坐标模式，之后恢复原模式。完整的“Moonlight 密码页输入后解锁”界面流程本轮未完成验收，不能把受控迁移当作该流程已通过。

上一轮显示空闲修正继续保留：控制台助手原先仅在准备或输入时重置显示空闲计时；无输入串流会使显示进入低功耗，产帧通道消失。修复在封闭 VDD 串流活动期间保持交互会话的显示请求，停止串流或改用标准采集时释放。修复前 60 秒显示空闲实验复现冻结；修复后同样实验持续 150 秒、182 秒无远端输入，实际运动画面与产帧正常，停止后请求释放且原 900 秒超时恢复。此前约 11 分钟运动画面、窗口/全屏、开始菜单及两次停止后重连通过。这些是上一轮版本的有限实测，不是全天稳定性或持续 144fps 性能证明。

客户端为当日最新稳定版 6.5.3 的既有必要维护版 `hdrfix.1`，默认 AMD D3D11VA 硬解、服务端 NVIDIA HEVC NVENC。官方 0.18.2 驱动继续保留，旧驱动和前一版 Sunshine 有保护备份；本轮安装包未重新构建。首次命令行自动启动曾停在应用列表加载且未进入 RTSP，该现象仍未归因。音频实听本轮未重测。上游后续 `bcbb5ec7` 的两项手柄/增强组件提交已拉取审阅，本轮保持 `d549e16a` 基线完成根因对照。
