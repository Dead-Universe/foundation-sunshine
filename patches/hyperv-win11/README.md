本轮 40 项 CTest 无失败，聚合套件 585 项中 21 项按上游环境条件跳过。Windows 原生 Shell 双向粘贴 80 MiB 文件、中文嵌套目录及空目录通过，SHA256 一致，源文件保留；超过 4 GiB 的定位、替换剪贴板及断开后的引用失效、重连后重新复制通过。用户已用资源管理器确认文件、文件夹双向粘贴正常。
